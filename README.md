# Nömrə Generatoru — Android APK

Bu proqram Python + Kivy ilə hazırlanıb.

## İş prinsipi

Məsələn:

`050 501 22 00`

və son rəqəm `99` seçildikdə:

`050 501 22 00`
`050 501 22 01`
`...`
`050 501 22 99`

## APK yaratmaq

Layihəni GitHub-a yüklə. Actions bölməsində `Build Android APK` workflow-u işə düşəcək. Build bitəndə `nomre-generator-apk` artifact-dan APK-nı götürüb Android telefona quraşdıra bilərsən.
